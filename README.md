# 南山智慧營運平台｜啟動前系統盤點

提供系統廠商填答、設備母檔及 I/O 資料收集、管理查詢及 CSV 匯出。資料儲存於伺服器 SQLite，不會寫入 GitHub。每棟每系統一份，原始設備清單、I/O 點表及介面文件應依南山核准管道另行提供，本版不提供附件上傳。

## 執行

需要 Node.js 22.13 或更新版本（建議 Node 24 LTS）。

```bash
export ADMIN_TOKEN='自行設定至少20字元的隨機管理密碼'
export SURVEY_TOKEN='自行設定另一組至少20字元的隨機填答密碼'
export DB_PATH='./data/inventory.sqlite'
node server.js
```

瀏覽 http://localhost:3000。管理及填答密碼必須不同；密碼不得提交到程式庫。生產環境請使用 HTTPS、持久化磁碟、備份，並依南山政策配置登入權限、存取紀錄、網路限制及資安檢測。此版為共享密碼，沒有個別帳戶、細緻權限、稽核軌跡或每份問卷的獨立連結；管理員密碼可讀取全部資料，填答者無法讀取回覆。瀏覽器會在本機保留未送出的草稿，公用電腦請勿使用敏感資料。

GitHub 儲存庫只存放程式碼，GitHub Pages 無法運行此 Node 伺服器及 SQLite；需另行部署到支援 Node 與持久化磁碟的環境，才能跨裝置共同填答。多台應用伺服器不能共用本機 SQLite，擴展時應改用共用資料庫。
